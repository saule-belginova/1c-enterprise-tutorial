Лабораторная работа № 2

Создание конфигурации и настройка свойств прикладного решения

Цель работы

изучить назначение конфигурации как основы прикладного решения на платформе «1С:Предприятие», освоить навыки создания новой конфигурации и настройки ее основных свойств в режиме «Конфигуратор».

После выполнения лабораторной работы студент должен:

  • понимать различия между платформой, конфигурацией и информационной базой;
  • создавать новую конфигурацию;
  • изменять свойства конфигурации;
  • задавать имя, синоним и комментарий конфигурации;
  • выполнять сохранение конфигурации;
  • обновлять конфигурацию базы данных;
  • запускать прикладное решение в режиме «Предприятие».

2.1. Теоретические сведения

Конфигурация представляет собой описание структуры прикладного решения и включает объекты метаданных, формы, программные модули и другие компоненты, предназначенные для автоматизации определенной предметной области.

Любая информационная система на платформе «1С:Предприятие» создается путем разработки конфигурации.

В процессе разработки программист работает с объектами конфигурации, определяет структуру данных и реализует бизнес-логику системы.

На начальном этапе конфигурация содержит только минимальный набор свойств и не включает прикладных объектов.

2.2. Профессиональная ситуация

Вы работаете в команде разработчиков, выполняющей проект автоматизации деятельности торговой организации.

После создания информационной базы руководитель проекта поручил подготовить основу будущей информационной системы.

Для этого необходимо создать новую конфигурацию и выполнить настройку ее основных параметров.

В дальнейшем данная конфигурация станет основой разрабатываемой информационной системы «ТорговаяКомпания».

2.3. Порядок выполнения работы

Задание 1. Открытие конфигурации

Шаг 1. Запуск информационной базы в режиме «Конфигуратор»:

  • Запустите программу «1С:Предприятие 8 (учебная версия)».

Шаг 2. Открытие конфигурации:

  • В открывшемся окне «Запуск 1С:Предприятия» выберите информационную базу «ТорговаяКомпания» и нажмите кнопку «Конфигуратор». После выполнения команды в левой части окна появится дерево конфигурации (Рисунок 2.1).
Рисунок 2.1 – Запуск информационной базы в режиме Конфигуратор

Режим «Конфигуратор» предназначен для разработки и настройки прикладных решений. В данном режиме создаются объекты конфигурации, выполняется программирование, настройка интерфейсов и администрирование информационной системы.

Задание 2. Изучение свойств конфигурации

Свойства конфигурации позволяют задать основные сведения о прикладном решении, необходимые как разработчику, так и пользователям системы. К числу наиболее важных относятся: имя конфигурации, синоним, комментарий, поставщик, версия, режим совместимости. Корректное заполнение свойств конфигурации является важным этапом разработки и сопровождения информационных систем.

Шаг 1. Открытие свойств конфигурации:

  • В дереве конфигурации выделите объект «Конфигурация».
  • Откройте окно свойств:
    Способ 1: Дважды щелкните мышью по объекту «Конфигурация».
    Способ 2: Выделите объект «Конфигурация» и нажмите клавишу F4.
    Способ 3: В контекстном меню объекта выберите команду Свойства

После выполнения команды откроется окно свойств конфигурации (Рисунок 2.2).

Шаг 2. Изучение основных свойств:

Изучите следующие свойства (Таблица 2.1):

Таблица 2.1 - Свойства конфигурации

Свойство Назначение Основные требования
Имя Внутренний идентификатор конфигурации. Используется платформой при разработке прикладного решения Имя должно начинаться с буквы; содержать только буквы, цифры и символ подчеркивания; не содержать пробелов; быть уникальным в пределах конфигурации. После выполнения задания студент должен понимать, что свойства конфигурации являются важным элементом проектирования прикладного решения и позволяют идентифицировать конфигурацию, описывать ее назначение, фиксировать информацию о разработчике и отслеживать версии программного продукта.

Задание 6. Проверка результатов

Шаг 1. Запустите систему в режиме «Предприятие». Для запуска выполните одно из следующих действий:

  • Способ 1: В меню выберите команду Отладка → Начать отладку
  • Способ 2: нажмите клавишу F5.
  • Способ 3: Нажмите кнопку запуска режима «Предприятие» на панели инструментов Конфигуратора.

Шаг 2. Подтверждение обновления.

Если система обнаружит изменения в конфигурации, появится сообщение «Конфигурация базы данных не соответствует сохраненной конфигурации».

В этом случае необходимо:

  • согласиться с обновлением;
  • дождаться завершения операции;
  • подтвердить запуск системы.

Шаг 3. Проверка запуска системы.

После запуска откроется окно режима «Предприятие».

На данном этапе конфигурация еще не содержит:

  • подсистем;
  • справочников;
  • документов;
  • отчетов;
  • обработок.

Поэтому рабочее окно будет практически пустым (Рисунок 2.6). Это является нормальным результатом выполнения лабораторной работы.
