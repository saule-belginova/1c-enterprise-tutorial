Лабораторная работа № 14

Язык запросов системы «1С:Предприятие»

Цель работы

получить практические навыки создания и выполнения запросов в системе «1С:Предприятие», освоить основные конструкции языка запросов, научиться выполнять отбор и сортировку данных, использовать параметры запроса и программно обрабатывать полученные результаты.

В результате выполнения лабораторной работы студент должен уметь:

  • создавать объект Запрос,
  • формировать текст простого запроса,
  • использовать конструкции ВЫБРАТЬ, ИЗ, ГДЕ, УПОРЯДОЧИТЬ ПО,
  • задавать параметры и обрабатывать результат запроса.
Задание 1. Подготовка обработки для выполнения запросов

Чтобы не перегружать форму документа «Поступление товаров» новыми учебными командами, для этой лабораторной работы удобно использовать отдельную обработку.

Шаг 1. Создание обработки:

  • В режиме «Конфигуратор» в дереве конфигурации найдите ветвь «Обработки».
  • Выберите команду «Добавить».
  • Для новой обработки задайте:
Свойство Значение
Имя РаботаСЗапросами
Синоним Работа с запросами

Шаг 2. Создание формы:

  • Перейдите на вкладку «Формы» обработки и создайте основную форму. Можно оставить предложенное платформой имя «Форма».
  • Откройте созданную форму.

Шаг 3. Включение обработки в подсистему (Рисунок 14.1):

  • Откройте свойства обработки «Работа с запросами» и перейдите в раздел «Подсистемы». В списке подсистем установите флажок «Отчеты». Это обеспечит доступ к обработке из соответствующего раздела пользовательского интерфейса.
  • После внесения изменений:
  1. сохраните конфигурацию;
  2. выполните Конфигурация → Обновить конфигурацию базы данных;
  3. запустите режим «1С:Предприятие»;
  4. убедитесь, что команда открытия обработки «Работа с запросами» появилась в соответствующем разделе.
  • После проверки вернитесь в Конфигуратор.

КонецПроцедуры

Разберем код:

1) Строка «Запрос = Новый Запрос» создает объект для работы с запросом.

2) Конструкция

Товары.Код,

Товары.Наименование

определяет, какие данные и откуда необходимо получить.

3) Команда «Запрос.Выполнить()» выполняет запрос.

4) Затем «Выборка = РезультатЗапроса.Выбрать()» создает выборку для последовательной обработки полученных записей.

5) Цикл «Пока Выборка.Следующий() Цикл» последовательно перебирает строки результата.

Шаг 2. Определите назначение его элементов.

Элемент Назначение
ВЫБРАТЬ Определяет получаемые поля
Товары.Код Получает код товара
Товары.Наименование Получает наименование товара
