Электронное учебное пособие «Основы конфигурирования 1С:Предприятие».

Лабораторная работа № 10

Основы программирования на встроенном языке системы «1С:Предприятие»

Цель работы

получить практические навыки использования основных конструкций встроенного языка системы «1С:Предприятие»: переменных, выражений, условных и циклических операторов, процедур и функций; научиться создавать, выполнять и анализировать простые программные алгоритмы.

В результате выполнения лабораторной работы студент должен уметь:

  • создавать простые фрагменты программного кода на встроенном языке;
  • использовать переменные различных типов;
  • выполнять арифметические вычисления;
  • формировать логические выражения;
  • использовать циклические конструкции;
  • создавать и вызывать процедуры;
  • создавать функции и использовать возвращаемые ими значения;
  • применять параметры процедур и функций;
  • выводить результаты выполнения программы;
  • находить простейшие ошибки в программном коде.

Порядок выполнения работы

Задание 12. Создание собственной процедуры

До настоящего момента все программные примеры выполнялись непосредственно в обработчике команды ВыполнитьПример. Однако при разработке прикладных решений отдельные действия целесообразно оформлять в виде самостоятельных процедур.

В данном задании необходимо создать собственную процедуру, предназначенную для вывода наименования товара, а затем вызвать ее из существующего обработчика команды.

Шаг 1. Открытие модуля формы.

  • В дереве конфигурации откройте Обработки → ОсновыПрограммирования → Формы → Форма1
  • Дважды щелкните по форме «Форма1».
  • В редакторе формы перейдите на вкладку «Модуль».
  • В модуле уже должна находиться созданная ранее процедура:

&НаКлиенте

Процедура ВыполнитьПример(Команда)

// программный код предыдущего задания

КонецПроцедуры

Шаг 2. Очистка тела обработчика команды.

Удалите из процедуры ВыполнитьПример программный код предыдущего задания, сохранив:

  • директиву &НаКлиенте;
  • заголовок процедуры;
  • строку КонецПроцедуры.

Шаг 3. Создание собственной процедуры.

После «КонецПроцедуры» существующего обработчика добавьте новую процедуру. Введите:

&НаКлиенте

Процедура ПоказатьТовар(Наименование)

Сообщить(Наименование);

КонецПроцедуры

Обратите внимание! Новую процедуру мы пишем не внутри «ВыполнитьПример», а после ее завершения. Т.е. одна процедура не должна объявляться внутри другой.

Шаг 4. Рассмотрите структуру созданной процедуры.

В строке:

Процедура ПоказатьТовар(Наименование)

Процедура — ключевое слово, обозначающее начало процедуры;

ПоказатьТовар — имя созданной процедуры;

Наименование — параметр, через который процедура получает значение;

КонецПроцедуры — завершение процедуры.

Таким образом, процедура «ПоказатьТовар» может получать различные наименования товаров и выполнять для них одно и то же действие.

Шаг 5. Вызов собственной процедуры.

Само создание процедуры еще не приводит к ее выполнению. Необходимо вызвать процедуру из обработчика команды «ВыполнитьПример».

В тело уже существующей процедуры добавьте:

Шаг 2. Подготовьте обработчик команды.

Шаг 3. Создайте функцию:

Важно. Функцию необходимо создавать отдельно от процедуры «ВыполнитьПример». Нельзя помещать определение функции внутрь другой процедуры.

Шаг 4. Рассмотрите структуру функции.

Проанализируем первую строку «Функция РассчитатьСумму(Количество, Цена)». Здесь:

  • Функция — ключевое слово, обозначающее начало функции;
  • РассчитатьСумму — имя функции;
  • Количество — первый параметр;
  • Цена — второй параметр.

Параметры позволяют передавать функции исходные данные непосредственно при ее вызове.

Например, если функции будут переданы значения 5 и 2500, внутри неее, то количество получит значение 5, а Цена — значение 2500.

Шаг 5. Рассмотрите оператор Возврат.

Основная строка функции «Возврат Количество * Цена» содержит оператор Возврат. Сначала вычисляется выражение «Количество * Цена» для наших исходных данных 5 × 2500 = 12500.

После этого оператор Возврат передает полученное значение обратно в то место программы, откуда была вызвана функция.

Именно возможность возвращать значение является главным отличием функции от рассмотренной ранее процедуры.

Шаг 6. Завершение функции.

Функция заканчивается ключевым словом «КонецФункции».

Шаг 8. Проанализируйте выполнение программы.

При нажатии кнопки «Выполнить пример» программа выполняется в следующей последовательности:
