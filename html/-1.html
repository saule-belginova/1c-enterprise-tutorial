Электронное учебное пособие «Основы конфигурирования 1С:Предприятие».

Лабораторная работа № 1

Создание информационной базы и знакомство со средой разработки «1С:Предприятие 8.3»

Цель работы

получить первоначальные практические навыки работы с платформой «1С:Предприятие 8.3», научиться создавать информационную базу, запускать основные режимы работы платформы и познакомиться со средой разработки Конфигуратор.

После выполнения лабораторной работы студент должен уметь:

•объяснять назначение информационной базы;
•создавать новую информационную базу;
•запускать режимы Конфигуратор и Предприятие;
•ориентироваться в интерфейсе платформы;
•понимать назначение основных элементов среды разработки.

Студент должен приобрести навыки:

•работы со средой разработки «1С:Предприятие»;
•создания новой информационной базы;
•подготовки рабочего проекта к дальнейшей разработке.

Для выполнения лабораторной работы необходимо:

•компьютер;
•операционная система Windows;
•установленная платформа 1С:Предприятие 8.3;
•доступ к локальному диску пользователя.
На данном этапе начинается создание новой информационной базы. В дальнейшем именно она станет основой разработки прикладной информационной системы «ТорговаяКомпания».

Минимальные требования к рабочему месту студента:

•операционная система (Windows 10/11);
•установленная платформа «1С:Предприятие» (учебная версия);
•рекомендуемый каталог для хранения информационных баз (C:\1CProjects);
•текстовый редактор (Microsoft Word или аналог);
•средство для создания скриншотов (например, «Ножницы» Windows).

Теоретические сведения

Платформа «1С:Предприятие» предназначена для разработки, настройки и эксплуатации прикладных информационных систем.

Работа с платформой начинается с создания информационной базы.

Информационная база представляет собой совокупность данных и структуры конфигурации, необходимых для функционирования прикладного решения.

Каждая информационная база является самостоятельным проектом. В течение всего семестра студенты будут разрабатывать собственную информационную систему именно в этой информационной базе.

В ходе лабораторной работы необходимо:

✓создать новую информационную базу;
✓выбрать файловый вариант хранения данных;
✓создать новую конфигурацию;
✓ознакомиться с интерфейсом Конфигуратора;
✓открыть режим Предприятия;
✓сохранить результаты работы.

Задание 1.1. Установка платформы

Шаг 1. Скачивание дистрибутива.

Перед выполнением лабораторных работ необходимо установить учебную версию платформы «1С:Предприятие 8.3».

Получить официальный дистрибутив можно на сайте фирмы 1С (действующая ссылка официального сайта фирмы 1С на момент создания электронного учебника):

https://online.1c.ru/catalog/free/learning.php?utm_source

На странице необходимо:

  • выбрать платформу «1С:Предприятие 8.3, учебная версия (Windows)»;
  • заполнить регистрационную форму;
  • принять условия лицензионного соглашения;
  • скачать дистрибутив программы;
Комментарий: не рекомендуется запускать программу установки непосредственно из ZIP-архива. Предварительная распаковка обеспечивает корректный доступ установщика ко всем необходимым файлам.

Шаг 2. Ответьте на вопросы:

  • Какие информационные базы отображаются в списке?
  • Какие команды доступны пользователю?

Задание 1.4. Ознакомление с интерфейсом режима «Предприятие»

Шаг 1. Запустите информационную базу в режиме «Предприятие»

Режим «Предприятие» предназначен для работы пользователей с информационной системой. В данном режиме выполняется ввод, обработка и анализ данных. На этапе создания новой информационной базы окно режима «Предприятие» не содержит элементов интерфейса, поскольку конфигурация еще не разработана.

Шаг 2. Найдите и изучите:

  • кнопку меню ☰;
  • строку поиска;
  • значки уведомлений;
  • избранное.

Шаг 3. Ответьте на вопрос: «Чем отличается данный режим от режима Конфигуратор?»

Шаг 4. Сохраните информационную базу. Закройте программу.

Индивидуальные задания

1) Самостоятельно изучите стартовое окно платформы и определите назначение следующих команд:

  • Добавить;
  • Изменить;
  • Настроить;
  • Удалить;
  • Конфигуратор;
  • Предприятие.

Полученные результаты оформите в виде таблицы.

2) Профессиональная ситуация

Представьте, что вы приняты на должность младшего разработчика в ИТ-компанию, занимающуюся автоматизацией предприятий. Руководитель проекта поручил вам подготовить основу новой информационной системы для торговой компании. Первым этапом разработки является создание информационной базы, в которой в дальнейшем будет разрабатываться конфигурация и храниться вся информация проекта.

В рамках данной лабораторной работы вы выполните первую задачу разработчика — создадите рабочую информационную базу, которая станет основой вашего проекта по данному курсу.

Контрольные вопросы

  1. Что представляет собой информационная база?
  2. Для чего используется режим «Конфигуратор»?
  3. Для чего предназначен режим «Предприятие»?
  4. Чем файловая информационная база отличается от клиент-серверной?
  5. Какие основные элементы интерфейса Конфигуратора вы изучили?
  6. Для каких целей используется дерево конфигурации?
