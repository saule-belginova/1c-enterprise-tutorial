Лабораторная работа № 3

Создание подсистем прикладного решения

Цель работы

освоить навыки создания и настройки подсистем в конфигурации «ТорговаяКомпания», изучить их назначение и роль в организации структуры прикладного решения.

После выполнения лабораторной работы студент должен:

  • понимать назначение подсистем;
  • создавать новые подсистемы;
  • настраивать свойства подсистем;
  • формировать структуру прикладного решения;
  • обновлять конфигурацию базы данных;
  • анализировать отображение подсистем в режиме «Предприятие».

Теоретические сведения

Подсистема является объектом конфигурации, предназначенным для логической организации прикладного решения.

Подсистемы позволяют объединять объекты конфигурации по функциональному назначению и формировать структуру пользовательского интерфейса.

Использование подсистем обеспечивает:

  • удобную навигацию;
  • логическую группировку объектов;
  • повышение удобства эксплуатации системы;
  • упрощение сопровождения прикладного решения.

Подсистемы не хранят данные и не выполняют вычислений. Их основная задача заключается в организации структуры прикладного решения.

Профессиональная ситуация

Вы участвуете в разработке информационной системы для торговой компании. На этапе проектирования принято решение разделить систему на функциональные области. Для повышения удобства работы пользователей необходимо создать подсистемы, отражающие основные направления деятельности предприятия.
