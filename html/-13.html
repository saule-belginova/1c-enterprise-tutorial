Лабораторная работа № 13

Работа с объектами, коллекциями и табличными данными

Цель работы

получить практические навыки программной работы с объектами и коллекциями системы «1С:Предприятие», освоить перебор строк табличной части, обращение к реквизитам строк, выполнение расчетов и проверку табличных данных, а также познакомиться с массивами и таблицами значений.

В результате выполнения лабораторной работы студент должен уметь:

  • программно обращаться к данным объекта документа;
  • определять количество строк табличной части;
  • использовать цикл «Для каждого ... Из ... Цикл»;
  • обращаться к реквизитам строки табличной части;
  • выполнять вычисления при переборе коллекции;
  • проверять корректность данных строк;
  • программно добавлять строки табличной части;
  • создавать и обрабатывать массивы;
  • понимать назначение таблицы значений и ее отличие от табличной части.

Порядок выполнения работы

Для выполнения лабораторной работы используется созданный ранее документ «Поступление товаров» и его табличная часть Товары.

В лабораторной работе будем постепенно создавать команды, позволяющие исследовать различные способы программной обработки табличных данных.

Задание 1. Подготовка формы документа

Шаг 1. Запустите информационную базу в режиме «Конфигуратор».

Шаг 2. В дереве конфигурации откройте:

Документы → ПоступлениеТоваров → Формы → ФормаДокумента.

На вкладке «Реквизиты» найдите основной реквизит формы «Объект».

Шаг 3. Раскройте его структуру и убедитесь, что среди данных документа присутствует табличная часть «Товары».

Шаг 4. Раскройте табличную часть и рассмотрите ее реквизиты (Рисунок 13.1). В нашей конфигурации при дальнейшей работе будут использоваться прежде всего:

  • Товар
  • Количество
  • Цена

Обратите внимание. В программном коде обращение «Объект.Товары» означает обращение ко всей табличной части документа.

При этом Товары представляет собой коллекцию строк, которую можно обрабатывать программными средствами.

Шаг 5. Проанализируйте конструкцию «Для Каждого СтрокаТовара Из Объект.Товары Цикл».

Задание 4. Расчет общей стоимости товаров

Используем перебор коллекции для выполнения практического расчета.

Шаг 1. Создайте команду:

Свойство Значение
Имя РассчитатьСумму
Заголовок Рассчитать сумму

Шаг 2. Создайте клиентский обработчик и разместите команду на форме.

Шаг 3. В обработчике команды укажите:

&НаКлиенте

Процедура РассчитатьСумму(Команда)

ОбщаяСумма = 0;

Для Каждого СтрокаТовара Из Объект.Товары Цикл

ОбщаяСумма = ОбщаяСумма

+ СтрокаТовара.Количество * СтрокаТовара.Цена;

КонецЦикла;

Сообщить("Общая сумма: " + Строка(ОбщаяСумма));

КонецПроцедуры

Шаг 4. Заполните в документе несколько строк с различными значениями количества и цены.

Шаг 5. Выполните команду «Рассчитать сумму».

Что происходит в программе?

Перед началом цикла «ОбщаяСумма = 0» создается переменная для накопления результата.

На каждой итерации рассчитывается стоимость очередной позиции «СтрокаТовара.Количество * СтрокаТовара.Цена» и прибавляется к ранее рассчитанной сумме.

После завершения цикла переменная «ОбщаяСумма» содержит итоговую стоимость всех товарных позиций документа (Рисунок 13.4).

Задание 6. Программное добавление строки

Исследуем изменение коллекции программными средствами.

Шаг 1. Создайте команду:

Свойство Значение
Имя ДобавитьСтроку
Заголовок Добавить строку

Шаг 2. Создайте клиентский обработчик и разместите команду на форме.

Шаг 3. В обработчике укажите:

&НаКлиенте

Процедура ДобавитьСтроку(Команда)

НоваяСтрока = Объект.Товары.Добавить();

НоваяСтрока.Количество = 1;

КонецПроцедуры

Шаг 4. В режиме «1С:Предприятие» нажмите «Добавить строку».

В табличной части должна появиться новая строка, для которой значение Количество установлено равным 1 (Рисунок 13.6).


Рисунок 13.6 - Результат программного добавления строки табличной части

Шаг 5. Проанализируйте код:

Метод «Объект.Товары.Добавить()» создает новый элемент коллекции.

Результат метода помещается в переменную «НоваяСтрока».

После этого можно обращаться к реквизитам созданной строки «НоваяСтрока.Количество = 1».

Таким образом, программа не только читает коллекцию, но и изменяет ее содержимое.
